# ZH JOKER TABLE · V3

像素风酒桌小游戏，当前包含：

- **小姐牌**：52 张牌随机不重复、抽牌历史、小丑起始牌、翻牌规则、小姐/K/存卡系统、深浅色主题、本地存档。
- **完整 A–K 卡面资产**：13 套独立像素插画，四种花色共享对应点数的中央插画。
- **大话骰**：5 个随机骰子、骰盅开合、重新摇、旋转/摇晃动画；仅 1 和 4 为红点，其余为黑点。
- **响应式**：手机优先，同时可在电脑浏览器中居中运行。

## 替换 GitHub 版本

1. 将本项目目录中的 `index.html`、`README.md` 和整个 `assets` 文件夹复制到本地 `zh-joker-table` 仓库根目录。
2. 选择“替换目标中的文件”。
3. GitHub Desktop 中填写 Summary：`V3 complete card art`。
4. 点击 **Commit to main**。
5. 点击 **Push origin**。
6. GitHub Pages 会自动重新部署，一般 1–3 分钟完成。

线上地址：
`https://zengheng9662.github.io/zh-joker-table/`

如果浏览器仍显示旧版，请使用 `Ctrl + F5` 强制刷新，或用无痕窗口打开。V3 已对主要图片资源添加缓存版本参数。
