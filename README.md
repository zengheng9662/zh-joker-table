# ZH JOKER TABLE

像素风酒桌小游戏集合，目前包含：

- 小姐牌：52 张牌随机不重复、抽牌历史、小丑起始牌、翻牌规则、小姐/K/存卡系统、深浅色主题、本地存档。
- 大话骰：5 个随机骰子、骰盅开合、重新摇、开盖状态下骰子旋转动画。

## GitHub Pages

建议仓库名：`zh-joker-table`

1. 创建 Public repository：`zh-joker-table`
2. 上传本目录全部文件到仓库根目录
3. GitHub → Settings → Pages
4. Build and deployment → Source 选择 `Deploy from a branch`
5. Branch 选择 `main`，Folder 选择 `/(root)`，保存
