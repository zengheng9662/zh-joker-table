# ZH JOKER TABLE

一款从真实聚会需求出发制作的轻量级网页小游戏，整合「小姐牌」与「大话骰」两种常用玩法。

## 🎮 项目介绍

这个项目来自我自己的聚会体验。

和朋友出去玩时，经常需要临时买一副扑克牌，用完之后基本就变成一次性消耗品；而使用手机小程序玩骰子时，又经常需要观看广告，也存在操作不透明、朋友互相怀疑“出老千”的情况。

因此，我尝试把这两个高频小游戏直接做成一个无需下载、打开网页即可使用的工具。

在视觉上，我结合自己的个人爱好，将页面设计成 **像素游戏风 UI**，并加入翻牌、骰子滚动等交互动效，让它不仅是一个工具，也更接近一个小型网页游戏。

同时针对真实聚会场景进行了手机与电脑端的响应式适配，尽量降低操作和使用门槛。

## ✦ 核心功能

### 🃏 小姐牌
- 随机抽取扑克牌
- 点击牌面即可翻牌
- 支持查看对应游戏规则
- 起始牌仅保留「小丑」图案
- 针对移动端翻牌体验进行优化

### 🎲 大话骰
- 一次生成 5 枚骰子
- 支持重新摇骰
- 1、4 点使用红色，其余点数使用黑色
- 骰子动画与像素风视觉统一

## ✦ 设计特点

- **像素游戏风 UI 与交互动效**
- **手机 / 电脑端自适应**
- 两种游戏模式快速切换
- 无需下载 App 或小程序
- 无广告、无需登录
- 基于 GitHub Pages 的轻量化部署

## ✦ 项目思路

这个项目并不是从“我要做一个网页”开始的，而是从一个很具体的使用场景出发：

> 能不能把聚会中经常需要的几个小工具，做成一个打开链接就能玩的网页？

因此在开发过程中，我更关注的是 **需求识别、功能取舍、交互路径和实际使用体验**，并通过多轮测试不断调整移动端布局、翻牌逻辑、视觉反馈与游戏规则展示方式。

## 🚀 Deployment

项目通过 **GitHub Pages** 部署。

将项目文件上传至仓库根目录后，通过：

`Settings → Pages → Deploy from a branch → main / root`

即可发布。
